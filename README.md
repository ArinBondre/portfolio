# Arin Bondre — Engineering Portfolio

Personal portfolio site for Arin Bondre (Arcadia High School), showcasing robotics, embedded systems, and hands-on engineering projects.

## Live website

**https://github.com/ArinBondre/portfolio/**

Open that link in any browser to view the site.

If the page does not load yet, GitHub Pages may still need to be turned on:

1. Go to [Repository Settings → Pages](https://github.com/ArinBondre/portfolio/settings/pages)
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**
3. Choose branch **main** and folder **/ (root)**
4. Click **Save**
5. Wait 1–2 minutes, then visit the link above again

## View locally

1. Open the project folder on your computer
2. Double-click `index.html`, or open it in a browser

No build step or server is required.
